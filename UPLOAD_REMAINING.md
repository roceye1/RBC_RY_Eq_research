1. Download `RBC_Independent_Research_GitHub_LinkedIn_Package.zip` from the ChatGPT conversation and extract it.
2. Open the extracted `rbc-ry-equity-research` directory.
3. Open [GitHub Add file → Upload files](https://github.com/roceye1/RBC_RY_Eq_research/upload/main).
4. Drag the entire `deliverables` and `assets` folders plus `build_research.py` onto that page (preserving folder structure). Commit to `main`.
5. Confirm that the PDF and PPTX links in README work and that [the repository is public](https://github.com/roceye1/RBC_RY_Eq_research).
6. Review the copyright disclaimer before sharing third-party imagery or research material.
